How the real system works
1. Train
YOLO11 trained on a 12-class Roboflow skin dataset (acne to melanoma) with PyTorch on CUDA.
2. Detect
The model draws a box around the affected area and scores each class.
3. Explain
The Streamlit app shows a plain-language explanation and can generate a detailed one.
4. Go live
The same detector runs on RTSP streams at 60+ FPS, with PaliGemma captions, OCR and speech.
